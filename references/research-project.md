# 持续更新研究项目

默认沿用当前用户已选项目，不因新增词根、重采或修改解读另建 HTML。用户明确选择“新建研究项目”时才使用新目录；多个候选项目无法判断时先确认，不擅自合并不同行业。项目路径由调用者提供，不在脚本中绑定某个人的知识库。

采集仍按原 JSON 检查点执行，导出 Excel 的流程不变。需要持续 HTML 时运行：

```powershell
python scripts/research_project.py --project "用户选定的研究目录" --input "本轮/capture.json"
```

固定入口为 `小红书关键词研究.html`，`research-project.json` 保存全部批次和原始来源记录，截图按内容哈希去重复制。重复导入同一 JSON 不增加批次。新增词根进入选择器；同词根默认显示最近完整批次；失败或不完整的新批次保存在历史中，不覆盖此前完整结果。尚无完整结果的词根明确标为采集未完成。根词之间共享的第二层检索保留全部来源关系。

报告使用已确认的白底、蓝紫强调色、圆角控件、大数字指标和蓝色渐变柱图风格，模板位于 assets/research.html、research.css、research.js。词根和历史批次可切换，支持全部词根、关键词筛选、来源证据与图表/表格切换。不自动生成运营解读、不显示跨批次差值比较，不把路径数当热度。所有新词默认待解读。原有定制报告不自动覆盖；它的手工分析不能搬作其他词根的结论。

报告本身无外部 JS/CSS，截图依赖同目录 evidence，分享时带整个项目文件夹；不得自动公开登录截图。原始 capture 和 Excel 保留在采集目录。脚本先校验再写入，状态为权威数据、HTML 可重新生成；文件系统中断时可能需按状态恢复视图。不得宣称两个文件具备跨文件事务。

采集优化：每轮共用检索队列去重，逐词检查点、稳定下拉后截图；遇到验证码或频控立即交给用户，不通过提高并发绕过限制。不自动开启定时采集。
